# Soumission du Projet Final - PyCon Togo 2026

Ce fichier sert à soumettre ton **projet final** du challenge 30 Days of Python 2026.

Le brief complet des projets (consignes, paramètres, ressources) est ici : [`Projects.md`](./Projects.md)

---

## Deadline

**20 août 2026, 23h59 (heure de Lomé, GMT).**
Seul le **dernier commit** reçu avant cette date et cette heure sera pris en compte. Aucune soumission après la deadline ne sera acceptée.

## 🚫 Règles d'intégrité

- Aucune utilisation d'IA Agent/générative/ou autres (ChatGPT, Copilot, Claude, etc.) n'est autorisée pour la réalisation de ces projets.
- **On ne triche pas son prochain** : chaque participant soumet son propre travail. Copier ou faire copier le code d'un autre participant entraîne la disqualification des deux personnes concernées.

## Marche à suivre
I. Soumettre via [Google Form et faire un feedback](https://docs.google.com/forms/d/e/1FAIpQLSfKYpXJ_yanrirn36MV7Iz6T8BLEPw-mc2WGipsmIcoC3YHOw/viewform?usp=dialog)

II. Faire la methode GitHub
1. **Fork** ce dépôt (`python-togo/30-Days-Of-Python`) sur ton propre compte GitHub.
2. **Crée ton projet** dans un dépôt GitHub personnel séparé (nom libre, ex. `zemidjan-calculator` ou `fcfa-currency-simulator`).
3. Dans **ton** dépôt de projet, ajoute un fichier `README.md` qui explique :
   - Le nom du projet
   - Comment le lancer (ex. `python main.py`)
   - Un exemple d'exécution ou une capture d'écran ou vidéo/lien de la vidéo youtube présentant le projet et son utilisation
4. Reviens dans **ce** dépôt (`30-Days-Of-Python`), et ajoute **une nouvelle ligne** dans le tableau ci-dessous avec tes informations.
5. Ouvre une **Pull Request** avec ta modification, avant le **19 août 2026, 23h59**.
